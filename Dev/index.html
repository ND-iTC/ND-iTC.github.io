Security requirements for the devices that run the network.

The ND-iTC brings together certification bodies, evaluation labs and vendors to write the requirements, and the tests, that Common Criteria security evaluations of network devices are built on.

The NDcPP and its Supporting Document are developed in the open. The working versions are on GitHub, where anyone can comment. Membership is for people who want to help write the next versions.
